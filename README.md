# Multi-Level-Stress-Classification

This repository contains the dataset used in the research paper **“Modeling Housewives’ Stress Levels Using IndoBERT with the Support of Indonesian Linguistic Features”**. The dataset consists of Indonesian text samples labeled with multiple levels of psychological stress. It is intended for research in natural language processing and classification tasks related to stress detection.



# 📌 Dataset Description

The dataset includes text entries collected from a social media online forum group platforms containing expressions of emotions, personal complaints, or stressful experiences.
Each text entry is annotated with a multi-level stress label based on predefined linguistic and psychological guidelines.
To ensure reliability, all labels were cross-validated by a team of licensed psychologists, following a multi-stage agreement and verification process.
The Stress level labels include:

Level 0 – No stress

Level 1 – Mild stress

Level 2 – Severe stress
